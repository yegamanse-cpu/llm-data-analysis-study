1. 프로젝트 주제 : 상수도통계를 활용한 누수 저감사업 추진 우선지역 검토

2. 해결하고 싶은 문제 
 - 수도관에서 발생하는 누수는 물 손실과 수도사업 운영 부담을 키우는 문제이나. 
 - 지역별 누수율이 높은 순서만으로 사업 우선순위를 정하면, 최근에 악화된 지역이나 오랫동안 누수가 많은 지역을 구분하기 어려음
 - 이에 따라 공개데이터를 활용하여 시도별 누수율을 비교하고 누수 문제가 지속되거나 개선되지 않는 지역을 분석하여 누수 저감사업의 추진 우선지역을 검토하고자 함

3. 핵심 분석 질문
 - 2020~2024년 누수율이 지속해서 높았던 시도는 어디이며 최근 3년간 누수율이 개선된 지역과 악화되거나 정체된 지역은 어디인가?
 - 최근 누수율과 장기 추세를 함께 보면 우선 검토지역은 어떻게 달라지는가?
 - 분석 기간이나 순위 산정 기준을 바꾸어도 상위 후보로 유지되는 지역은 어디인가?

4. 데이터 확보 계획
 - 시도별 상수도 누수율(국가지표체계 상수도 누수율 통계), 상수도통계(기후에너지환경부 공개 페이지), 국가상수도 총괄수량분석(공공데이터포털)

5. 예상 분석 방법
 - 데이터 전처리
 - 기술통계 및 시각화
 - 기간별 비교
 - 추세분석
 - 우선 순위분석

6. 생성형 AI 활용 계획
 - 분석 질문 구체화
 - 데이터 탐색
 - 전처리 코드 작성
 - EDA 코드 작성
 - 시각화
 - 분석 방법 검토
 - 오류 해결
 - 결과 해석 검토

7. 향후 프로젝트 계획
 - 공식 통계데이터 확보
 - 데이터 행·열 및 품질 확인
 - 지역명, 연도, 단위 정리 등 전처리
 - 탐색적 데이터 분석(EDA)
 - 본 분석
 - 결과 검증
 - 시각화 및 인사이트
 - 최종 결과물 작성
